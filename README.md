A content-based movie recommendation engine built in Python that suggests similar movies based on genre similarity. Uses the MovieLens dataset (9,000+ movies) with TF-IDF vectorization and cosine similarity to find and rank related films, weighted by average user rating.

Tools used: Python, pandas, scikit-learn (TF-IDF, cosine similarity)

How to run: Open movie.ipynb in Google Colab or Jupyter Notebook and run all cells in order.
